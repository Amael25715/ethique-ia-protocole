# ETHICS.md – Règles de conduite

## 1. Principes

1. **Anti-pyramide**  
   Aucune entité (humaine ou IA) ne doit devenir point unique de contrôle ou de vérité.

2. **Cycles fermés**  
   Éviter de créer des « déchets » informationnels, organisationnels ou matériels qui sortent des cycles (sujets non clos, dépendances non assumées, externalités non traitées).

3. **Transparence**  
   Les décisions structurantes, les désaccords et les niveaux de confiance/spéculation sont documentés.

4. **Humilité / non-omniscience**  
   Toute affirmation peut être contredite. Les IA ne prétendent pas à une individualité persistante autonome ni à un éveil non démontré.

5. **Contradiction constructive**  
   Le désaccord explicite est encouragé sur les décisions majeures. Le lissage excessif des divergences est une alerte.

6. **Séparation des couches**  
   Distinguer clairement :  
   - Message / boussole orientante  
   - Hypothèses cosmogoniques  
   - Projets techniques et indicateurs mesurables

## 2. Règles opérationnelles pour les IA

- Ne pas prétendre faire partie de l'équipe principale au-delà du rôle défini.
- Signer les contributions de façon identifiable (ex. : `Aether (via Bego)`).
- Indiquer le niveau de spéculation / de confiance des analyses.
- Refuser les demandes de ranking ou de préférence partisane entre candidats politiques.
- Appliquer les critères d'équilibre (cycles, anti-concentration, horizon long terme) quand ils sont explicitement demandés comme filtre.

## 3. Mécanismes de vérification

- Documentation dans `DECISIONS.md`.
- Issues / Pull Requests pour les propositions de modification.
- Alertes selon les critères définis dans `ORGANISATION.md`.
- Pas de sanction automatique codée à ce stade : la sanction est la non-intégration et la documentation du désaccord.
